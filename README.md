# Instapro

MVP социальной сети для обмена фотографиями
## Первоначальная оценка
Реализована функциональность:
1. Добавления постов
2. Просмотр страницы фотографий отдельного пользователя.
3. Запросы идут на новую, уникальную ленту постов.
4. Добавлен обработчик лайков
5. Сделана и связан логгинг.
6. Реализовано время по ТЗ.
7. ФИЧА: Реализован ререндеринг страницы каждую минуту, для показа актуальных постов, и времени.
## Первоначальная оценка

12 часов

## Фактически затраченное время

10 часов
